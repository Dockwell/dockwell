# Icon

Line icons on a 24-unit grid with a 1.5 stroke and round joins, drawn in `currentColor`.

**You provide** `name` and, when the icon stands alone without a label, `label` for screen readers.

- 16px in controls and lists, 14px in small buttons and tags, 20px only in empty states.
- Icons inherit text colour; they are ink-muted by default and ink when active.
- Status is never an icon. Use StatusBadge glyphs for state.
