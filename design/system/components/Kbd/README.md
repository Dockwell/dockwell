# Kbd

A key cap that teaches a shortcut where the action lives.

**You provide** one key per `Kbd` (`⌘` and `K` are two caps). Use symbols on macOS (⌘ ⌥ ⇧ ↵) and words elsewhere (Ctrl, Enter).

- Put shortcuts inside buttons with `Button kbd`, beside menu and command-bar rows, and in empty states that teach.
- Never use a key cap as decoration or for a value the user types.
