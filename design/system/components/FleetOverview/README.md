# FleetOverview

The Fleet screen of Dockwell, built only from this system's components and tokens, as the reference for composing a full page.

- Rail on the left, top bar with ScopeBar, command entry and the one primary action, then the page on `canvas`.
- The page leads with its title and one line of context, then at most one Callout, four Metric panels, the FleetGrid beside the Timeline, and the services Table.
- Use it to check spacing, density and theme behaviour of new components in context.
