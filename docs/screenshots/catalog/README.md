# Catalog app pages

These screenshots show the panel from this change in Chromium, using a temporary local install with fixture data. They cover the catalog grid and app details before installation, on desktop in both themes and on a 390 px phone. They are review images, not bundled panel assets.

- [Catalog, light](catalog-light.webp)
- [PostgreSQL, light](app-light.webp)
- [T3 Code, dark](app-dark.webp)
- [Coder, phone](app-phone.webp)

The images retain the captured layout. Desktop images show the page content with the surrounding server shell cropped out. The grid and phone images show the initial viewport; the desktop app images show the whole page content. They are encoded as WebP for size. App artwork within the pages retains its [source notices](../../../web/public/catalog-media/NOTICE.txt).
